# Тестовое задание на позицию Junior системный аналитик

Репозиторий с решением тестового задания компании Effective Mobile (2025) для интернет-магазина «Петрушка Зелёная». Задание состоит из трёх частей: анализ требований, проектирование API и верхнеуровневая архитектура push-уведомлений.

## Ссылка на исходное задание
https://github.com/yanalaska-analyst/effective-mobile-test-sa

## Что сделано
- **Часть 1 (Анализ требований):** найдены логические противоречия и недочёты в ТЗ по корзине, предложена исправленная версия фрагмента и уточняющие вопросы PM.
- **Часть 2 (Проектирование API):** описан REST-запрос `GET /api/v1/stores` для экрана магазинов, приведён пример JSON-ответа по макету, прописана обработка ошибок (404, 500, 503).
- **Часть 3 (Архитектура):** построена верхнеуровневая блок-схема отправки push-уведомлений.

## Что не сделано и почему
Не спроектирована аналитика доставки пушей (отслеживание открытий) и не проработана логику сегментации для маркетинговых рассылок — верхнеуровневая схема показывает путь от события до устройства, а эти детали на него не влияют

## Как читать решение
1. Открой файл `t1-answers.md` — ответ на первое задание (анализ требований).
2. Открой файл `t2-answers.md` — ответ на второе задание (проектирование API).
3. Блок схема для задания 3 сохранена в файле `arch.mermaid` — ответ на третье задание (архитектура).

## Как проверяли
- Текст в первом задании проверен на логическую непротиворечивость.
- Пример JSON во втором задании проверен на валидность и соответствие макету.
- Схема в третьем задании проверена на соответствие требованию «верхнеуровневость».
